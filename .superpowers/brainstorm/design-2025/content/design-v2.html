What Changes vs What Stays

✅ Changes (layout only)

  • Sidebar: white bg, subtle border, rounded active pill
  • Top bar: greeting + date subtitle, cleaner CTA placement
  • Metric cards: icon circle top-left, trend badge top-right
  • Posts: pill filter tabs, cleaner table header, row actions
  • Analytics: improved tab layout, chart spacing
  • CreatePost: two-column form + live preview pane
  • Settings: section cards with clear grouping
  • Consistent 10px card radius, 8px button radius throughout

🔒 Stays the Same

  • All colors — #0a66c2 primary, green/amber/red status
  • LinkedIn Vault — glassmorphism untouched
  • Automation — glassmorphism untouched
  • All API calls, stores, business logic
  • Component library (shadcn/ui)
  • Fonts (Orbitron display, Plus Jakarta Sans body)
  • Dark/light mode tokens
  • All routes and navigation structure
